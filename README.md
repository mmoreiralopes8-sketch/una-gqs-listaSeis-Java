# una-gqs-listaSeis-Java

Projeto da disciplina de Gestao e Qualidade de Software - UNA.

## Sobre
Algoritmo em Java que realiza as quatro operacoes basicas (soma, subtracao, multiplicacao e divisao).

## Tecnologias
- Linguagem: Java
- IDE: Visual Studio Code
- Versionamento: Git e GitHub

## Como executar
javac Calculadora.java
java Calculadora


Algoritino para testes de versionamento com a turma!
